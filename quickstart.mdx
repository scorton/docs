# Quickstart

## 1. Open the portal

Sign in at [https://developers.scorton.dev/auth](https://developers.scorton.dev/auth). That host is the Developer Portal. API calls below use the same origin.

## 2. Create an account

Signup creates:

1. A portal account
2. A **Cyberscor** user on `api.scorton.dev` (`POST /v1/cyberscor/auth/signup`)

The portal keeps both sessions. Scans send the Cyberscor JWT as `x-cyberscor-token`.

## 3. Mint a platform token

Go to **API Tokens** → create a key. You get a value like `scrt_…`.

- Stored by the portal
- Verified with `GET /api/verify-key` + header `x-api-key` (or Bearer `scrt_`)
- Unlocks `/api/scan`, raw MCP `POST /api/mcp`, and `/api/gateway/*` (TrustScore + Cyberscor)
- Stay signed in so your Cyberscor JWT is sent as `x-cyberscor-token` for upstream security scores

<Note>
  Platform tokens are **not** Radar keys from `radar.scorton.tech`. The portal owns key issuance.
</Note>

## 4. Score a domain

On **Scan URL**:

1. Paste `scrt_…` and click **Verify**
2. Enter a host (e.g. `example.com`)
3. Run scan

The portal calls `POST /api/scan`, which:

1. Validates the platform key
2. Tries upstream `POST /v1/cyberscor/score` with your Cyberscor JWT (if present)
3. Falls back to a portal DNS + security-headers score if containers/auth fail

## 5. Connect MCP (Cursor / Claude)

With `SCORTON_API_KEY` set on the portal server, point MCP at the **raw** portal proxy:

```json
{
  "mcpServers": {
    "scorton": {
      "url": "https://developers.scorton.dev/api/mcp",
      "headers": {
        "Authorization": "Bearer scrt_YOUR_PLATFORM_TOKEN"
      }
    }
  }
}
```

```bash
curl -X POST https://developers.scorton.dev/api/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer scrt_YOUR_PLATFORM_TOKEN" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

Platform tokens do **not** authenticate directly against `mcp.scorton.dev` — the portal verifies `scrt_` and swaps in the service key.

## 6. Use ScortonJS

```bash
pip install scortonjs
scorton score example.com
```

Or see [ScortonJS](/sdks/scortonjs) for TypeScript / CLI examples pointed at `api.scorton.dev`.

## Local development

The hosted portal is [developers.scorton.dev](https://developers.scorton.dev). To run this repo yourself:

```bash
npm run dev        # http://localhost:3100
npm run docs:dev   # http://localhost:3000
```

Copy `.env.example` to `.env.local`. Set `NEXT_PUBLIC_APP_URL=http://localhost:3100` so Stripe return URLs stay on the dev server.
