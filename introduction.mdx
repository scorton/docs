# Scorton Developer Portal

The [Developer Portal](https://developers.scorton.dev) is where you sign in, mint a platform key (`scrt_…`), score hosts, and connect Cursor or Claude to MCP. One key unlocks API scan, the portal gateway, TrustScore, Cyberscor (JWT optional for upstream), and raw MCP.

Start at [developers.scorton.dev/auth](https://developers.scorton.dev/auth).

## One token, full access

| Credential | Unlocks |
| --- | --- |
| Platform key `scrt_…` | `POST /api/scan`, `POST /api/mcp`, `/api/gateway/*`, `GET /api/verify-key` |
| Cyberscor JWT (login) | Upstream Cyberscor score via `x-cyberscor-token` (portal DNS + headers fallback without it) |
| Portal session | Mint and list keys only |

Send the platform key as `x-api-key: scrt_…` or `Authorization: Bearer scrt_…`. For Cursor, point MCP at `https://developers.scorton.dev/api/mcp` with that Bearer token.

## What the portal contains

| Area | Path | What you do |
| --- | --- | --- |
| Dashboard | `/` | See whether `api.scorton.dev` and `mcp.scorton.dev` are up |
| API Tokens | `/tokens` | Create a platform key and run Access check |
| Scan URL | `/scan` | Verify the key and score a host |
| Integrations | `/integrations` | Copy MCP config and gateway routes |
| Profile | `/profile` | Account details |
| Usage | `/usage` | Calls this period |
| Activity | `/activity` | Recent requests |
| Settings | `/settings` | Plan, billing, and webhooks |

## Stack

| Surface | Host | Role |
| --- | --- | --- |
| Dev Portal | [developers.scorton.dev](https://developers.scorton.dev) | Auth, tokens, scan UI, MCP gateway |
| API | `https://api.scorton.dev` | Cyberscor + TrustScore REST |
| MCP | `https://mcp.scorton.dev` | Agent tools (proxied through the portal) |
| ScortonJS | [js.scorton.dev](https://js.scorton.dev) | OSS CLI / SDK |

<Note>
  Platform `scrt_` tokens do not authenticate directly against `mcp.scorton.dev`. Use the portal proxy (`POST /api/mcp` or `/api/gateway/mcp`).
</Note>
