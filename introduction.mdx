# Scorton Developer Portal

The app is [developers.scorton.dev](https://developers.scorton.dev). Sign in, mint an `scrt_` key, score a domain, and connect MCP. These pages follow that app, not the older Radar or `api.scorton.tech` flows.

Open it at [developers.scorton.dev/auth](https://developers.scorton.dev/auth).

## What the portal contains

| Area | Path | What you do |
| --- | --- | --- |
| Dashboard | `/` | See whether `api.scorton.dev` and `mcp.scorton.dev` are up |
| API Tokens | `/tokens` | Create a platform key (`scrt_…`) |
| Scan URL | `/scan` | Verify the key and score a host |
| Integrations | `/integrations` | Copy the MCP config and gateway routes |
| Profile | `/profile` | Account details |
| Usage | `/usage` | Calls this period |
| Activity | `/activity` | Recent requests |
| Settings | `/settings` | Plan, billing, and webhooks |
